# Ownership index — shared facts

> Facts more than one spec depends on. A spec either **points here** or defines the fact
> locally. Silently redefining a shared fact in a second spec is a Gate 1 miss
> (`.agent/rules/governance.md` DoR).

**Maintained with** the spec that first recorded the fact. Later specs cite the row ID.

| OWN-10 | **The authoritative request/stage state and transition contract** — every request status, every stage status (including `COMPENSATION_REQUESTED` / `COMPENSATED` / `COMPENSATION_FAILED` / `FAILED`), every legal transition, and which spec performs each one — is the table in `internal-transfer-request` § _Authoritative State and Transition Contract_. | OWN-11 | **The request aggregate carries one monotonic `version`.** Every mutation from any spec increments it by exactly 1 using compare-and-swap (`UPDATE … WHERE version = :expected`); the loser is refused with 409 `version-conflict` and never merged. Downstream API01 does not: it uses the in-transaction read as `:expected`, with `eventId` idempotency checked first (byte-identical replay does not increment). A withdrawal losing to an approval gets `version-conflict` while the request is still withdrawable, and `withdrawal-window-closed` once it has reached `FULFILMENT`.
